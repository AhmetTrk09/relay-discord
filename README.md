# Üçüncü taraf kaynakları

Rota ile dağıtılan GoodbyeDPI, zapret, WinDivert ve Cygwin bileşenlerinin kaynak arşivleri ve lisansları bu dalda tutuluyor. Arşivler değiştirilmedi.

Uygulamayı indirmek için [Rota sürümlerini](https://github.com/AhmetTrk09/rota-discord/releases/latest) kullanabilirsin. Bu dal uygulamayı çalıştırmak için gerekli değil.

`archives/` klasöründe kaynaklar, `licenses/` klasöründe lisans metinleri var. Bileşen sürümleri ve özgün kaynak adresleri `dependencies.lock.json` dosyasında.

Bu kaynaklar Rota 0.3.1 içinde dağıtılan ağ bileşenleriyle eşleşir. Bileşenler güncellenirse önceki kaynaklara erişim korunarak bu dal da güncellenir.
